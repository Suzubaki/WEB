# Финальная инструкция

## Запуск приложения локально:
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Инициализируйте БД и пользователей:
   ```bash
   python create_users.py
   ```
3. Запустите сервер:
   ```bash
   python app.py
   ```
4. Откройте в браузере: `http://localhost:5000` или `http://127.0.0.1:5000`
