## 🔧 КАК РАЗВЕРНУТЬ НА PYTHONANYWHERE:

### ШАГ 1: Подготовка файлов
1. **Скачай все файлы** из папки `livestock_accounting/`
2. **Убедись, что есть все необходимые файлы:**
   ```
   app.py, auth.py, database.py, config.py, charts.py, models.py
   requirements.txt, pythonanywhere_wsgi.py
   templates/ (вся папка)
   static/ (вся папка)
   ```

### ШАГ 2: Загрузка на PythonAnywhere
1. **Войди на** https://www.pythonanywhere.com под логином `Suzubaki`
2. **Перейди во вкладку Files**
3. **Создай папку:** `/home/Suzubaki/livestock_accounting/`
4. **Загрузи все файлы** в эту папку
   - Можно загрузить ZIP архив и распаковать
   - Или загрузить файлы по одному

### ШАГ 3: Создание веб-приложения
1. **Перейди во вкладку Web**
2. **Нажми "Add a new web app"**
3. **Выбери:**
   - ✅ Manual configuration  
   - ✅ Python 3.9

### ШАГ 4: Настройка WSGI
1. **В разделе Code** нажми на ссылку WSGI configuration file
2. **УДАЛИ всё содержимое** файла
3. **ВСТАВЬ содержимое** из файла `pythonanywhere_wsgi.py`
4. **Сохрани** файл

### ШАГ 5: Установка зависимостей
1. **Перейди во вкладку Consoles**
2. **Создай новую Bash консоль**
3. **Выполни команды:**
   ```bash
   cd /home/Suzubaki/livestock_accounting/
   pip install -r requirements.txt
   ```

### ШАГ 6: Настройка статических файлов
1. **Вернись во вкладку Web**
2. **В разделе Static files добавь:**
   - URL: `/static/`
   - Path: `/home/Suzubaki/livestock_accounting/static/`

### ШАГ 7: Перезапуск и проверка
1. **Нажми кнопку Reload** вверху страницы Web
2. **Перейди по своей ссылке:** `suzubaki.pythonanywhere.com`
3. **Войди с тестовыми аккаунтами:**
   - Админ: `admin` / `admin123`
   - Ферма 1: `farm1` / `farm123`
   - Ферма 2: `farm2` / `farm123`

## 🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

### Проверка проблем:
1. **Запусти тестовый скрипт** в консоли PythonAnywhere:
   ```bash
   cd /home/Suzubaki/livestock_accounting/
   python test_pythonanywhere.py
   ```

2. **Проверь логи ошибок** во вкладке Web → Error log

3. **Убедись, что:**
   - Все файлы в правильной папке
   - Зависимости установлены
   - WSGI файл настроен правильно
   - База данных создана (создается автоматически при первом запуске)

### Частые проблемы и решения:

**Проблема:** "ImportError: No module named 'app'"
**Решение:** Убедись, что `app.py` в папке `/home/Suzubaki/livestock_accounting/`

**Проблема:** Ошибки с зависимостями
**Решение:** Переустанови зависимости:
```bash
pip install --upgrade -r requirements.txt
```

**Проблема:** Ошибки с путями
**Решение:** Проверь WSGI файл, убедись что пути правильные

**Проблема:** Статические файлы не загружаются
**Решение:** Проверь настройки Static files на PythonAnywhere
