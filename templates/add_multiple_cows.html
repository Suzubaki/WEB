Массовое добавление коров

Инструкция

Введите данные о нескольких коровах в формате JSON. ID коровы будет сгенерирован автоматически для каждой фермы.

Каждая корова должна содержать следующие поля:

  • category - категория выбытия: "падёж", "выбраковка" или "санитарный"
  • reason - конкретная причина выбытия (из списка категории)
  • disposal_date - дата выбытия в формате ГГГГ-ММ-ДД
Поле cow_id больше не нужно! ID будет сгенерирован автоматически в формате: {{ farm_name }}-001
